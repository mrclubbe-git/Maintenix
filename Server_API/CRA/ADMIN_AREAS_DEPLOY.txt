Restart
-------
Restart only the CRA DEV service:

sudo systemctl status maintenix-dev-api.service --no-pager

Health validation
-----------------
curl -i http://127.0.0.1:5056/api/health
curl -i https://dev-api.main-tenix.com/CRA/api/health

Both should return HTTP 200 with {"ok":true}.

Functional validation
---------------------
1. Sign in as an ADMIN and open Administration -> Areas.
2. Confirm baseline areas are listed and known Sections are available.
3. Add a genuinely new Area from Servicing or Call Out.
4. Confirm the new Area remains immediately usable.
5. Confirm data/area-metadata.json contains a PENDING record.
6. Confirm Admin receives the "Area metadata required" notification.
7. Open the notification and verify it deep-links to:
   #/administration?tab=areas&status=pending
8. Configure Section/Base area/F/G metadata in Administration -> Areas.
9. Confirm the Area becomes CONFIGURED.
10. Generate a future servicing report for that Area and confirm report storage uses the configured Section.
11. Do not move historical reports automatically.
